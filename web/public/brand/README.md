# Podpora digitalizace

Oficiální barevné pozitivní RGB logo Ministerstva kultury. Původní SVG je
uloženo beze změny; web pouze nastavuje jeho prezentační šířku na 150 px při
zachování poměru stran. Text „Zdigitalizováno ve VISK 6“ doplnil projekt
na výslovný pokyn provozovatele k oběma zpřístupněným rukopisům.

- Zdroj: https://www.mk.gov.cz/logo-jednotny-vizualni-styl
- Soubor: https://www.mk.gov.cz/doc/cms_library/logo_mk_barevne-pozitivni_rgb-21403.svg
- Převzato: 2026-10-16
- SHA-256: `4a56caf133530ed276a94a4d57280c0fb888235bc23a70f8719144030ff0facf`

Logo se vztahuje k digitalizaci předloh. Tento blok neposuzuje financování
výzkumného webu, přepisů nebo výkladů AI. Rukopisné obrazy nadále do Gitu nepatří.
